# Code of Conduct

We expect contributors to keep discussions respectful, technical, and focused on improving Setorra.

## Standards

Examples of behavior that helps the project:

- clear technical feedback
- respectful disagreement
- reproducible bug reports
- privacy- and security-conscious contributions
- patience with new contributors

Examples of unacceptable behavior:

- harassment or personal attacks
- discriminatory language
- publishing private information
- intentionally disruptive behavior
- pressuring maintainers to disclose security issues publicly

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or contributions that violate this code of conduct. Repeated or severe violations may result in a ban from the project.

Report conduct concerns privately to the maintainers.
